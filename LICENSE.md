## Plain-English guide (not part of the license)

Farglow follows the **Minecraft model**: anyone can run a server for their friends or community for free. Running Farglow as a **paid** service needs a commercial license from Citus Technologies.

| You want to… | Allowed? |
|---|---|
| Read, download, build and change the code | **Yes** |
| Run a Farglow server for yourself, friends, a club, a school or a public community, at no charge | **Yes** (Additional Use Grant) |
| Accept voluntary donations to cover server costs, with no perks, priority or exclusive access in return | **Yes** |
| Share your changes or a fork, under this same license | **Yes** |
| Charge players to join or play, sell subscriptions, or sell in-game advantages on your server | **No.** Ask for a commercial license |
| Sell Farglow hosting to others ("we run a Farglow server for you") | **No.** Ask for a commercial license |
| Use the name "Farglow", "Generative Distractions" or the logos for your server or fork | **No**, apart from saying truthfully that it runs or is based on Farglow. Trademarks are not licensed |
| Use a version under Apache 2.0 with no restrictions | **Yes**, four years after that version is first released |

**Why this license.** It is source-available, not "open source" in the OSI sense, so don't describe Farglow as open source. Two alternatives were considered and rejected:
- **Elastic License 2.0**, recommended earlier, forbids offering the software "as a hosted or managed service" at all. That would block free community servers, the core of the model.
- A fully open license would let anyone sell hosting immediately.

BUSL 1.1 restricts only what we name in the Additional Use Grant, and every version becomes Apache 2.0 after four years.

**Not covered by this license:**
- **Trademarks:** the Farglow and Generative Distractions names and logos. A trademark policy will follow.
- **Third-party components,** which keep their own licenses. The fonts Inter Tight and IBM Plex Mono are under the SIL Open Font License 1.1, and every dependency's license is listed in `THIRD_PARTY_NOTICES.md`.
- **AI models a host connects,** such as Ollama models or API providers. These are governed by their own terms.
- **Content players create** on a server, such as messages and names. It belongs to the players, subject to that server's rules.

**Contributions.** Outside contributions are accepted only under a Contributor License Agreement. The CLA lets Citus Technologies offer commercial licenses and relicense on the Change Date. See `CONTRIBUTING.md` (to be written).
