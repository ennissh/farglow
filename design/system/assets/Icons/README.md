# Icons

Single-ink SVGs on a 24px grid, 1.5px stroke, round caps and joins. The ink in these files is **#141A22** (light-theme ink). In the product, draw icons with `FarglowArt.icon(name)` from `lib/farglow-art.js` instead: it uses `currentColor`, so icons follow the theme and the text colour around them.

Sizes: 16px in dense tables, 20px default, 24px in panel headers. Never below 16px.
